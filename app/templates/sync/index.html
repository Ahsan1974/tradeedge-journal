Sync from MT5

How closed trades get into TradeEdge (and what is not possible)

Can I sync from MT5 Mobile?

No. MetaTrader mobile (Android/iOS) has no API for apps like this. Only the Windows Exness MT5 desktop can be read by TradeEdge (via the MetaTrader5 Python package). Trades you open on mobile still land on the same Exness account — sync them later from the Windows terminal.

Why the live website Sync button fails

Opening this site on your Windows PC still runs the app on Vercel’s servers (in the cloud). Those servers cannot see your Exness terminal. Sync must run on your PC, writing into Neon — then refresh the website.

Fastest: one-click sync

  1. Open Exness MetaTrader 5 on Windows and stay logged in.
  2. Double-click D:\Trading Dashboard\scripts\Sync_MT5.bat
  3. Wait for the success message, then refresh this website.

Auto-update every 30 minutes

Keep your PC on with MT5 open. Install once in PowerShell:

cd "D:\Trading Dashboard"
.\scripts\install_sync_scheduler.ps1

Remove later with .\scripts\uninstall_sync_scheduler.ps1

Sync from anywhere without MT5 API

If you’re away from the PC, use CSV import on this site:

  1. On any device, export history from MT5 (or use the EA export file).
  2. Go to Trades → Import and upload the CSV.
